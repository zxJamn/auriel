# Auriel

A set of views for Obsidian: the Hall, the daily note, your habits and journal, and the themes they wear.

- **downloads/Auriel Basic.zip**: the free edition, as a vault. Extract it, then in Obsidian choose *Open folder as vault*.
- **downloads/Auriel Setup.exe**: the same for Windows, which can also add Auriel to a vault you already keep.
- **catalogue.json**: what the Store tab inside the vault lists.

Prices, help and everything else: https://auriel.me
